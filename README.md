# 주문 한 장

아소비몰 주문 상세 내역을 붙여넣고 **훗타운 일반 배송·THE 빠른배송·짐패스·포스트몰** 업로드용 엑셀을 만드는 도구입니다.

## 사용 방식 선택

| 방식 | 링크와 설명 |
| --- | --- |
| 온라인에서 사용 | [주문 한 장 열기](https://order-sheet-oct30-7k4m.yellow-cocoa-5065.chatgpt.site) |
| 코드를 직접 확인하거나 AI에 검토 요청 | [공개 GitHub 저장소](https://github.com/masudaayano156/asobimall-order-excel) · [개인정보 처리와 검토 안내](SECURITY.md) |
| 인터넷 연결을 끊고 사용 | [최신 오프라인 ZIP 다운로드](https://github.com/masudaayano156/asobimall-order-excel/raw/refs/heads/main/downloads/offline.zip) · [파일 SHA-256 목록](https://github.com/masudaayano156/asobimall-order-excel/raw/refs/heads/main/downloads/checksums.txt) |

오프라인 ZIP을 압축 해제한 뒤 `order-excel-offline.html`을 브라우저로 열면 됩니다. 코드·공개 상품 목록·네 엑셀 양식이 한 HTML 안에 들어 있어 별도 서버나 설치가 필요하지 않습니다.

상품 카드와 상품 후보 목록에는 미리 준비한 공개 상품 썸네일을 표시합니다. 썸네일도 오프라인 HTML에 포함되므로 외부 이미지 서버에 주문 정보를 보내지 않고 확인할 수 있습니다.

## 주문을 엑셀로 만들기

1. 사이트에서 배대지를 선택합니다. 기본값은 **훗타운**이며, 일반 배송과 THE 빠른배송 중 사용할 서비스를 선택합니다.
2. 아소비몰에서 **English**를 선택하고 영어 표시가 완료될 때까지 기다립니다.
3. 주문 상세를 펼쳐 `Order No.`, 상품명, `Product amount`, `quantity`가 포함되도록 선택해 복사합니다. 여러 주문을 이어서 붙여넣을 수 있습니다.
4. 주문 내용을 읽어온 뒤 상품·옵션·수량·금액과 수취인 정보를 확인합니다. 훗타운 상품명이 80자를 넘으면 수량 안내와 중복 표현을 정리해 자동 축약합니다. 짐패스 상품명은 영문·숫자·공백 형태로 괄호·하이픈 등의 기호를 정리하고 영문·숫자 기준 10~100자를 확인합니다. 원문은 상품 카드 제목에서 확인하며, 상품 연결·품목 분류에는 원래 이름을 사용합니다.

여러 주문을 함께 붙여넣으면 상단에서 전체 합계를 확인하고, 아래에서 주문번호별 상품·합계·배송비·운송정보를 확인할 수 있습니다. 원문 결제금액이 있는 경우 주문 구획에 별도로 표시하며, 각 주문의 상품 목록은 접거나 펼칠 수 있습니다.
5. 운송사와 트래킹번호를 주문별로 입력하거나, 나중에 배대지에서 입력하도록 선택합니다. **추후 입력**을 선택한 운송정보는 기존 입력값이 있어도 엑셀에서 공란으로 나갑니다.
6. 원하는 양식으로 다운로드하고 내용을 확인한 뒤 배대지에 직접 업로드합니다.

상품·이미지 URL은 공개 카탈로그에서 고유하게 일치하는 상품을 찾았을 때 연결합니다. 비슷한 이름만 일치하거나 같은 이미지·이름을 쓰는 상품이 여러 개면 자동 확정하지 않습니다. 상품별 품목코드도 제안하므로 재질과 실제 물품에 맞는지 확인해 주세요.

상품별 상세 검토 결과는 `dist/product-classifications.json`에, 전체 커버리지는 `dist/classification-coverage.json`에 저장합니다. 상품 ID·코드·원래 이름·공식 URL이 모두 맞을 때만 해당 매핑을 적용하며, 상세 출처·해시와 배대지 코드표를 함께 보존합니다. 혼합 랜덤 구성은 상세에서 확인된 범위만 넓은 잡화 항목으로 제안하고, 소재 미기재·센터별 제한 등 근거가 부족한 항목은 확인 필요로 표시합니다.

실물 없는 전자 참가권으로 확인된 항목은 표시 후 배송용 엑셀에서 제외합니다. 디지털 사진집이라도 실물 다운로드 카드를 배송하는 상품은 카드류로 포함합니다.

미완료 항목은 빨간 테두리와 안내로 표시합니다. 모르는 값을 채우지 않은 파일은 **초안**으로 내려받을 수 있습니다. 아소비몰의 `Product amount`는 상품 1개당 단가로 사용하며, 상품 합계는 단가 × 수량으로 계산합니다. 쇼핑몰 배송비는 상품 단가에 합산하지 않습니다.

상세 구성에서 문구·장식·파우치 등 잡화의 혼합이 확인된 랜덤 굿즈에는 짐패스 `205`·훗타운 `291`을 넓은 범주의 **자동 제안**으로 미리 채웁니다. 배대지의 품목별 확정 안내나 HS 분류를 뜻하지 않으며 확인 필요 상태를 유지합니다. 구성 미공개, 의료용품 포함, 지정된 혼합 추첨 상품은 이 제안 대상에서 제외합니다.

온라인 실행에서는 우편번호 옆 **우편번호 찾기**를 누르면 카카오 주소 검색창이 열립니다. 결과를 선택하면 우편번호·기본주소가 채워지고 상세주소 칸으로 이동합니다. 기본주소를 바꾸면 기존 상세주소는 지워지므로 동·호수는 다시 입력해 주세요. 검색창에 직접 입력한 검색어는 카카오로 전송됩니다. 주문·수취인명·연락처·통관부호·기존 주소를 검색창에 전달하지 않습니다. 파일을 직접 여는 오프라인 실행에서는 우편번호와 주소를 직접 입력합니다.

연락처는 짐패스 선택 시 하이픈을 자동으로 넣고, 훗타운 일반·빠른배송 선택 시 숫자만 표시합니다. 입력 예시와 다운로드한 엑셀에도 같은 형식을 적용하며, 배대지를 변경해도 전화번호의 숫자는 유지합니다.

최상단과 엑셀 다운로드 전 팝업에는 신청 정보를 직접 한 번 더 확인하라는 안내를 표시합니다. 팝업에서 돌아가기를 선택하면 다운로드를 진행하지 않고 입력 화면을 유지합니다.

훗타운의 고정배송비 코드는 배송 유형과 별도인 선택 사항입니다. THE 빠른배송은 운송장 1개·배송 박스 1개로 오는 여러 상품을 신청할 수 있습니다. 공식 Quick 양식을 사용하며, 이 양식에는 주문번호·옵션·상품 URL·이미지 URL 열이 없습니다.

일반 배송은 `General_Excel_Upload.xlsx`, THE 빠른배송은 `Quick_Excel_Upload.xlsx` 양식으로 작성합니다. 빠른배송용 다운로드 파일에는 `_THE빠른배송`을 붙여 일반 양식과 구별합니다.

엑셀 고정배송비 신청은 원본 Quick `신청서!AK10`·General `신청서!AW10`에 명시된 대로 신청서별 상품 단건·수량 1개일 때만 가능합니다. THE 빠른배송 서비스 자체는 운송장 1개·박스 1개의 여러 상품을 허용하며, 이 경우 고정배송비는 신청하지 않습니다. 고정배송비를 선택하면 단건·수량 조건과 코드표의 센터·배송 유형·실제 품목이 맞는지 확인합니다. 개별 코드의 수량·중량 등 추가 조건도 배대지에서 확인해야 합니다. 품목 자체를 고정요금 대상에 맞춰 임의 변경하지 않습니다.

고정배송비 코드는 원본 참조표의 숫자 키와 같은 숫자 셀로 작성하며, 오른쪽 명칭 검증 수식과 계산 결과를 함께 유지합니다. 품목번호·운송장번호·우편번호 등의 문자열 형식은 유지합니다.

훗타운 화면에서 확인한 코드별 수량·중량 조건은 접힌 상세조건에서 볼 수 있습니다. 홈페이지 조건과 엑셀 일괄 신청 조건을 구분하며, 템플릿에 적힌 오래된 요금이 현재 요금으로 오인되지 않도록 선택 옵션에서는 금액을 표시하지 않습니다. 엑셀 참조표와 검증 명칭은 원본 양식을 유지합니다.

훗타운의 점검용 이름·코드 열은 원본 관리 수식과 다운로드 시점의 계산 결과를 함께 보존합니다. Excel에서 원래 입력 항목을 수정하면 관리 열도 자동으로 다시 계산됩니다.

## 포스트몰 가로 양식

포스트몰은 `Postmall-v2.1-horizontal.xlsx`를 사용합니다. 헤더 3행 아래인 4행부터 신청서를 한 행씩 작성하며, 신청서 한 행에는 상품을 최대 20개까지 배치합니다. 21개째 상품을 조용히 누락하거나 다른 신청서로 임의 분할하지 않고 입력 오류로 표시합니다. 현재 제공 양식 범위인 신청서 297행까지 파일을 만들며, 이는 이 도구의 처리 범위입니다.

포스트몰의 `HS_CODE`는 짐패스·훗타운 품목번호와 다른 코드입니다. 상품명과 공개 상세 자료를 [포스트몰 공식 HS 찾기](https://www.postmall.net/hs-finder)·HS 분류 자료를 바탕으로 저장한 규칙과 대조해 코드를 자동 제안합니다. 일반적인 실물 사진카드·엽서·포스터·달력·인쇄 책자도 상품명에서 종류를 추정할 수 있으면 제안하며, 추정 근거와 확인할 소재·구성을 표시합니다. ChooseMe 종이 세트는 확인된 특정 상품과 구성에 한정해 사진·그림 인쇄물 후보를 제안합니다. 구성 미공개 혼합 굿즈나 소재별 코드 구분이 필요한 미확인 의류 등은 임의 코드로 채우지 않습니다.

자동 제안은 확정 분류가 아니므로 실제 상품과 맞는지 확인하고 수정할 수 있으며, 사용자가 입력하거나 지운 HS 값은 배대지를 전환해도 유지합니다.

HS 규칙은 현재 페이지에서 실행하며 주문명·수취인 정보를 외부 HS 검색에 보내지 않습니다. 공식 검색 링크는 검색어 없는 새 창으로만 엽니다. 점·공백을 정리한 숫자 6·8·10자리만 받으며, HS 미입력 상태의 파일은 초안으로 표시합니다. 원본 양식에 HS의 필수·선택 여부가 명시되어 있지는 않으므로 실제 업로드 전 확인해야 합니다.

주문자 이름·연락처를 별도로 입력하지 않으면 한국 수취인 정보를 사용합니다. 통관 구분은 원본 안내에 따라 모르면 공란이며, 포장 방식과 부가서비스는 사용자가 선택한 값만 작성합니다. 일본 주문에서는 캐나다산 FTA 항목을 작성하지 않습니다. 이 양식에는 국가·입고센터·통화·현지 운송사 열이 없으므로 포스트몰 사이트에서 일본 센터를 선택하고 업로드합니다.

## 입력 정보 처리

이 저장소의 변환 코드는 입력한 주문·수취인 정보를 현재 페이지 메모리에서 처리합니다. 이를 서버로 보내거나 브라우저 저장소에 저장하는 기능은 작성되어 있지 않습니다. 내려받은 엑셀은 사용자의 기기에 파일로 남습니다.

온라인 화면은 같은 사이트의 공개 상품 목록·설정 JSON과 선택한 XLSX 양식을 불러옵니다. 영어 상품명은 사이트를 준비할 때 공개 상품명만 번역해 저장한 자료입니다. 방문자의 주문·수취인 정보를 번역 서비스에 보내지 않습니다.

온라인 호스팅은 이 저장소와 별도로 동작합니다. 현재 배포 환경에서 Cloudflare 봇 탐지 코드가 HTML 응답에 추가되는 것을 확인했으며, 호스팅의 접속 기록까지 이 저장소에서 제어하거나 검증하지는 않습니다. 오프라인 ZIP은 호스팅이 HTML에 코드를 추가하지 않도록 원본 HTML을 압축해 제공합니다. 압축된 HTML의 CSP는 `connect-src 'none'`을 사용하고 외부 코드·스타일 로더를 포함하지 않습니다.

처리 경로, 파일 검증 방법과 복사해서 사용할 AI 검토 요청문은 [SECURITY.md](SECURITY.md)에 있습니다. 해시나 AI 검토 결과는 보안 인증을 뜻하지 않습니다.

## 개발·검증

Node.js 22와 npm을 사용하는 환경에서 아래 순서로 실행합니다. 로컬 HTTP 미리보기에는 Python 3를 사용할 수 있습니다.

```sh
git clone https://github.com/masudaayano156/asobimall-order-excel.git
cd asobimall-order-excel
npm ci
npm run build:offline
npm test
python -m http.server 8765 --directory dist --bind 127.0.0.1
```

미리보기 주소는 `http://127.0.0.1:8765`입니다. 오프라인 산출물을 검사하는 테스트가 있으므로 `npm test` 전에 빌드가 필요합니다.

`dist/index.html`을 파일로 직접 열면 같은 폴더의 단독 실행본 `offline.html`로 자동 연결됩니다. 화면이나 코드를 수정한 뒤 파일로 열어 확인하려면 `npm run build:offline`으로 실행본도 갱신하세요.

`npm run build:offline`은 다음을 만듭니다.

- `dist/offline.html`: 로컬 검증용 단일 HTML
- `dist/offline.zip`: 같은 HTML 원본, 사용 안내, fflate 라이선스
- `dist/source.zip`: 허용 목록에 포함된 공개 소스·데이터·양식·검증 테스트
- `dist/checksums.txt`: 두 ZIP 파일의 SHA-256

빌드에는 고정된 개발 의존성 esbuild 0.25.12를 사용합니다. 런타임 ZIP 처리는 저장소에 포함된 fflate 0.8.3을 사용하며, 해당 라이브러리의 MIT 라이선스는 [dist/fflate-LICENSE.txt](dist/fflate-LICENSE.txt)에 있습니다.
